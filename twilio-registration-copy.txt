CAMPAIGN DESCRIPTION
TextMe Reminders is a personal reminder application. Users create reminders for themselves and explicitly opt in to receive scheduled SMS reminder messages at their mobile number. Messages may include one-time or recurring reminders. Users can reply to complete or snooze reminders and can opt out at any time by replying STOP.

MESSAGE FLOW / HOW END-USERS CONSENT
Users opt in by following the public instructions on the TextMe Reminders website at YOUR_HOME_URL. The page instructs the user to text START to YOUR_TWILIO_NUMBER. The disclosure states that the user is agreeing to receive recurring automated reminder messages from TextMe Reminders, that message frequency varies, that message and data rates may apply, and that the user can reply STOP to opt out or HELP for help. The page also links to the Privacy Policy and Terms & Conditions. Reminder messages are sent only after the user has opted in.
